You might keep most of your BTC in an on-chain wallet and use Lightning or Arkade for everyday transactions. But when you want to use an application on Rootstock, you need funds on that network. How to get from the wallet you already use to the asset the application needs?

Satora is adding swaps between rBTC on Rootstock and BTC on Bitcoin on-chain, Lightning, and Arkade. This brings another part of the Bitcoin ecosystem into the same swap experience, connecting the balances people already hold with more places to use them.

## Why connect to Rootstock?

[Rootstock](https://rootstock.io/) gives developers an environment for building smart contracts and financial applications around Bitcoin. It is a separate sidechain, compatible with the Ethereum Virtual Machine, so developers can work with familiar Ethereum tools to build services such as trading and lending applications.

For users, that creates reasons to move funds onto Rootstock. Someone who wants to use rBTC in an application needs to obtain it in a compatible wallet first. rBTC is also the asset used to [pay transaction fees on Rootstock](https://dev.rootstock.io/concepts/rbtc/), so it has a practical role throughout the experience.

Connecting Rootstock to Bitcoin on-chain, Lightning and Arkade gives users more starting points for that journey. They can choose a swap based on where they hold their BTC, rather than treating access to Rootstock as something disconnected from their existing wallet setup.

## From a Bitcoin balance to a Rootstock application

Take someone who has BTC in a Lightning wallet and wants to use an application that accepts rBTC. Through Satora, they can select Lightning, on-chain, or Arkade as the source, request rBTC on Rootstock, and provide a compatible receiving address. After reviewing the quote and following the payment instructions, a completed swap delivers rBTC to that wallet.

From there, the user decides what to do with it. Using a Rootstock application is a separate step, with its own transaction fees and conditions. The swap provides access to the asset; Rootstock and the application retain their own security assumptions.

For Satora, this integration extends the role of swaps beyond moving between Bitcoin and stablecoins. It also connects different ways of using Bitcoin, letting users move towards the network an activity requires from the balance they already have.

[Open Satora](https://app.satora.io/) to choose a Rootstock route and review the quote before making a swap.
